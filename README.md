# Tree-Based File Manager

An extracted module from a larger custom chat application, isolated here to showcase a tree-structured file/folder management system — one of the more complex pieces of that product's front end.

> **Note:** This repository is a focused excerpt of a larger private codebase (a custom chat platform), kept standalone to highlight the file-management logic specifically.

## What this demonstrates

- Recursive, tree-structured folder/file navigation and rendering
- State management for nested, hierarchical data structures
- Handling non-trivial UI complexity (expand/collapse, nested actions, tree updates) cleanly

## Tech Stack

- React
- Vite

## Running locally

```bash
pnpm install
pnpm dev
```

Open the local URL shown in your terminal to explore the file tree.
